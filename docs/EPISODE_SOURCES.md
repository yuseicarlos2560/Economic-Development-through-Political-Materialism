# Episode Sources Register — Step 3, Phase B annotation layer

**Purpose.** Every judgment-coded determination in `data_clean/episodes.csv` (73 episodes) rests on
named, citable sources. This register is the annotation layer: it lists the anchor sources by category,
maps each episode to its anchors per judgment area, grades source quality, and records what was verified
and what remains imprecise. `episodes.csv` itself is unchanged (coded state preserved); the machine-readable
companion is `data_clean/episode_sources.csv` (one row per episode, generated by `code/build_episode_sources.py`).

**Judgment areas annotated** (per Coding Protocol §6): (1) *prior tie* — the patron relationship (or
non-alignment) existing before the episode; (2) *change* — the instrumental act(s) constituting the entry,
severance, or severance threat, and the coded interval; (3) *voluntariness* — coerced vs. voluntary;
(4) *validation* — independent corroboration (UN ideal points, datasets, admissions).

**Source classes.** **P** = primary instrument/record (treaty, protocol, executive order, law, communiqué,
declassified record). **D** = dataset record (ATOP, GSDB-R5, UN ideal points, DOTS, Archigos, CCP, WDI/WEO).
**S** = secondary scholarly/reference account.

**Quality grades.** **A** = load-bearing judgments anchored by primary instruments.
**B** = anchored by dataset records + named acts, with some reliance on secondary dating or a pending
judgment flag. **C** = qualitative/secondary basis where no formal instrument exists for a load-bearing
judgment (by construction, not by neglect).

**Verification tags.** `V-2026-11` = verified against sources during the 3 Nov 2026 sourcing pass
(see Verification log). `SR` = standard scholarly reference, not re-verified this pass.
`DS` = carried by the cited dataset record. `FLAG` = known imprecision, listed under Weak spots.

Conventions referenced below (patron set, ALBA, SEATO artifact, etc.) are the Coding Protocol §6.2
decisions; open items are tracked in `docs/OPEN_ISSUES.md`.
